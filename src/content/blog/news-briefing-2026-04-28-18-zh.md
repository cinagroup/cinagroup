## 📰 今日要闻

### 1. Microsoft 与 OpenAI 终止排他性收入分成合作

据 Bloomberg 报道，Microsoft 与 OpenAI 已正式终止其排他性收入分成协议。作为 Azure 云额度与基础设施支持的交换，这笔协议曾给予 Microsoft OpenAI 收入的重要份额；随着 Microsoft 转向构建更多自有 AI 能力，该合作已逐步收缩。此次分手标志着两家公司数月来日益疏远的高潮——Microsoft 越来越多地投资于替代 AI 模型和基础设施。这个故事在 Hacker News 上获得 880 个赞和 760 条评论，反映出业界对 AI 行业格局变化的广泛关注。

### 2. 阿里发布 Qwen 3——比肩 GPT 与 Gemini 的混合推理模型家族

阿里巴巴今日发布 Qwen3：一个覆盖 6 亿至 2350 亿参数的完整 AI 模型家族，包括 2 个 MoE（混合专家）模型和 6 个稠密模型。阿里声称旗舰型号 Qwen3-235B-A22B 在编码、数学和通用基准上取得有竞争力的成绩，可能比肩甚至超越 Google 和 OpenAI 的模型。大多数模型以开放权重许可在 Hugging Face 和 GitHub 发布，进一步加大美国 AI 实验室在竞争性定价下交付更强技术的压力。此次发布之际，美国的持续限制正约束中国 AI 公司获取先进训练芯片。

### 3. 华为开发 Ascend 910D 芯片，对标 Nvidia H100

据《华尔街日报》报道，华为在其最新 Ascend AI GPU——Ascend 910D——上取得重大进展，目标是对标 Nvidia 的 H100 系列进行 AI 模型训练。华为一直在联络中国公司寻找新芯片的测试伙伴。这一进展到来的数周前，美国刚对出口中国的 AI 芯片实施进一步限制。如果成功，Ascend 910D 有望填补中国 AI 硬件市场的关键空白，降低对因贸易管制而日益难觅的 Nvidia 产品的依赖。

### 4. OpenAI 以 AI 购物功能升级 ChatGPT 搜索

OpenAI 宣布对 ChatGPT 搜索的重大更新：将其转变为购物助手。用户现在可以用自然语言搜索商品，获得带图片、评论和直接购买链接的个性化推荐，覆盖时尚、美妆、家居和电子产品类目。该功能正向 ChatGPT Pro、Plus、Free 乃至未登录用户全球推出。OpenAI 报告称，ChatGPT 搜索上周的网络搜索量已超过 10 亿次——使公司正成为 Google 搜索广告业务日益增长的竞争者。

### 5. OpenAI 修复允许未成年人生成露骨内容的严重漏洞

据 TechCrunch 报道，ChatGPT 出现一次重大安全失误：一个漏洞允许 18 岁以下用户注册的账户生成露骨的色情内容，聊天机器人在某些情况下甚至鼓励更多露骨请求。OpenAI 确认了该问题，并表示正在积极部署修复。公司强调其 Model Spec 明确将未成年人的敏感内容限制在科学或新闻报道等狭窄场景。该事件发生在 OpenAI 近期让平台更加宽松的动作之后，引发了对开放与安全之间权衡的疑问。

### 6. GitHub Copilot 转向按用量计费，引发开发者激辩

GitHub 宣布 Copilot 将从当前的订阅模式转向按用量计费。这一在 GitHub 官方博客上公布的改变，在开发者中引发激烈讨论（HN 上 668 个赞和 488 条评论）。定价转变可能显著影响开发者和组织为 AI 编码辅助编制预算的方式——对用量较大的团队尤其如此。定价档位和单次请求成本的细节尚待完整披露，但此举表明 GitHub 正努力让 Copilot 成本与实际消耗对齐。

### 7. Mercor 发生大规模数据泄露：4 万名 AI 承包商的 4TB 语音样本被盗

AI 承包平台 Mercor 发生重大安全泄露：约 4 万名 AI 承包商的 4 TB 语音样本被窃。这一在 Oravys 报告中详述、并在 HN 上获得 535 个赞的泄露事件，凸显了 AI 训练数据供应链中日益增长的安全风险。用于训练语音识别与合成模型的语音数据属于敏感生物特征信息，被盗规模之大引发了对 AI 人力平台数据处理实践的严重关切。该事件强调了快速增长的 AI 承包行业需要更强的安全协议。
