## 📰 今日要闻

### 1. Gartner 调查：80% 的 CEO 称 AI 将迫使运营能力大改

Gartner 对 469 位高管的 2026 年 CEO 调查显示：80% 的 CEO 预期 AI 将推动运营能力发生中到高度变革——从数字化业务转向自主化业务。只有 13% 的 CEO 预期到 2028 年仍停留在任务级自动化，而今天这一比例为 54%。值得注意的是，28% 的 CEO 认为交易型收入面临直接风险——AI 智能体可以绕过中介系统，进行实时定价和谈判。

### 2. Braze 发布 BrazeAI Operator 与 Agent Console，进军智能体营销

Braze（纳斯达克：BRZE）在其伦敦 City x City 活动上发布了 BrazeAI Operator™ 和 BrazeAI Agent Console™：让营销人员能够在营销活动工作流中构建、管理和部署自主 AI 智能体。平台报告显示，Cleo 的退订率降低了 81%，Dayuse 的预订转化率提升了 90%。一项 Forrester 研究引用了三年 457% 的 ROI，回本周期不足六个月。

### 3. ZillizTech 发布 Claude-Context MCP，实现全代码库集成

ZillizTech 推出了专为其 Claude Code 设计的新模型上下文协议（MCP）"claude-context"。该工具将整个代码库转化为 AI 编码智能体的全面上下文，弥合了大规模仓库与 AI 驱动开发之间的鸿沟。该项目已在 GitHub 上形成趋势，凸显出对更深代码感知 AI 工具的需求不断增长。

### 4. Anthropic 暂缓发布 Claude Mythos 5——首个被认为过于强大而不能发布的模型

Anthropic 确认了 Claude Mythos 5，但宣布不会公开发布或通过标准 API 提供：该模型触发了公司的 ASL-4 安全协议。这个 10 万亿参数的混合专家模型设有专门面向网络安全、学术研究和复杂软件工程的集群。其网络安全能力可以构建完整的多阶段攻击链——这是前沿实验室首次建造出一个被认为过于强大而不能部署的完整模型。

### 5. NIQ 推出 Commerce Lab，用于 AI 驱动的商务测量

NielsenIQ 宣布 NIQ Commerce Lab：将自己定位为智能体商务的中立测量基础设施。该平台将提供数据 API，告诉 AI 智能体有哪些商品可用、消费者实际买了什么、营销活动是否带来了增量收入——填补 Amazon、Google 和 Meta 在商务测量中留下的利益冲突空白。

### 6. RuView：将 WiFi 信号转化为实时人体姿态估计

ruvnet 的一个突破性项目将标准商用 WiFi 信号转化为全面的人体数据——实现实时姿态估计、生命体征监测和在场检测，全程无需摄像头。这种以隐私为核心的方法分析信号扰动而非视觉图像，为隐私至上的环境中的健康追踪和空间感知提供了新颖方案。

### 7. Claude Code 称霸 2026 年 4 月 AI 编码工具排行榜

独立排行榜确认，Claude Code 在 2026 年 4 月的所有 CLI 与智能体类 AI 编码工具中位居第一，OpenAI 的 Codex 紧随其后。Anthropic 在五周内发布了超过 30 个 Claude Code 版本，改进了渲染周期、企业云设置和 Linux 进程隔离。与此同时，Ars Technica 对 Claude Code 源码泄露的分析揭示了持久化智能体、隐秘的"Undercover"模式以及代号"Buddy"的虚拟助手计划。
