## 今日七大新闻

### 1. Cloudflare 裁员 1100 人，AI 用量暴涨 600%

Cloudflare 宣布裁减 1100 名员工，明确将此次裁员定性为面向"智能体 AI 时代"的重组，而非削减成本的举措。公司报告其 AI 相关用量已增长 600%，并正在把资源重新分配到 AI 原生运营上。此举表明基础设施公司正在以何等速度围绕 AI 需求重组其员工队伍——即便整体营收依然强劲。

### 2. Musk 诉 Altman 案第二周回顾：取证视频主导庭审

Elon Musk 与 OpenAI 之间的法律战进入第二周，前 OpenAI 内部人士的取证视频轮番登场。Tasha McCauley 作证称，Altman 领导下的 OpenAI 弥漫着"说谎与欺骗的文化"；前董事会成员 Helen Toner 详述了 2024 年 11 月罢免 Altman 的过程。董事会甚至在危机期间讨论过与 Anthropic 合并，并考虑让 Dario Amodei 出任 CEO。Musk 的专家证人 David Schizer 就非营利组织治理作证，不过观察人士认为交叉质询并未令人信服。结案陈词预计将在一周内进行。

### 3. 据报道 Meta 员工在裁员与 AI 强制令下"痛苦不堪"

《纽约时报》的一篇报道揭示了 Meta 内部的普遍不满：公司一边追踪员工电脑活动以训练 AI 模型，一边准备裁减 10% 的员工，还激进地要求每个团队构建 AI 智能体。员工形容自己所处的环境是"其他人不得不引入智能体来找智能体，再引入智能体来评估智能体"。许多人不再把 Meta 视为长期职业归宿，一些员工主动释放信号想要拿到遣散费。

### 4. Google 将 Gemini API 文件搜索扩展至多模态 RAG

Google 宣布 Gemini API 文件搜索（File Search）现已支持多模态检索增强生成（RAG），开发者可以跨包含文本、图像和其他媒体格式的文档进行搜索。这一升级让构建需要异构数据源推理能力的 AI 应用时获得更丰富的上下文理解。对于使用 Gemini API 构建文档智能工作流的企业开发者而言，这是重要一步。

### 5. Mozilla 披露由 Claude Mythos 发现的 271 个 Firefox 漏洞

Mozilla 采取了不同寻常的步骤：公开分享由 Anthropic 的 Claude Mythos Preview 模型发现的 271 个 Firefox 漏洞的详细报告，绕过了通常将此类报告保密数月的政策。公司援引"围绕这一话题的非凡关注度"和"整个软件生态采取行动的紧迫性"作为加速披露的理由。此举凸显了 AI 在自动化安全研究中日益重要的角色，也提出了一个问题：行业应如何处理 AI 发现的漏洞。

### 6. OpenAI 发布 Codex Chrome 扩展实现浏览器自动化

OpenAI 为 Chrome 发布了一款 Codex 浏览器扩展，允许这一编码智能体与用户已登录的网站和 Web 应用交互。该扩展在"任务专用"的标签页分组中运行，将智能体的浏览器会话与用户的活动标签页隔离开来。这代表着 OpenAI 推动Codex 成为更通用的自动化工具、能够跨 Web 应用处理真实世界工作流的努力。

### 7. 研究论文："委托 LLM 管理文档时，它们会损坏你的文档"

一篇新的 arXiv 论文（2604.15597）正在引发大量讨论：其研究发现，把文档管理委托给 LLM 会导致系统性的文档损坏。这篇在 Hacker News 上累计超过 400 个赞和 160 多条评论的论文记录了语言模型在被要求编辑或管理文档时引入细微错误、幻觉内容和格式退化的方式。该研究进一步证明：AI 委托存在组织可能未曾计入的隐性质量成本。
