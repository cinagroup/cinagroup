## 今日七大新闻

### 1. OpenAI 发布 GPT-5.6 Sol,迄今最强大的模型

OpenAI 发布了 **GPT-5.6 Sol**——其旗舰模型系列的最新迭代。据报道,早期基准显示它在推理、编程和多模态任务上领先于以往所有版本。发布之际,距 Anthropic 自己的模型更新仅数周——两大 AI 领袖之间的军备竞赛正在加速而非降温。

行业观察人士指出,Sol 似乎专为智能体工作流优化——自主规划并执行多步任务的能力——OpenAI 和 Anthropic 都在这一领域重仓投入。模型将首先面向企业客户和 API 用户推出,消费者访问预计随后跟进。

### 2. OpenAI 揭晓万众期待的"超级应用"

这可能是 OpenAI 自 ChatGPT 以来最雄心勃勃的产品动作:发布一款统一的**"超级应用"**,在一个界面下整合聊天、代码生成、图像创作和智能体任务执行。这款应用已开发一年有余,被视为对 Anthropic Claude 生态的直接回应——后者在企业采用上步步进逼。

超级应用深度集成第三方服务,并包含插件市场,定位 OpenAI 捕获更多 AI 工作流层,而不仅仅是充当模型供应商。早期采用者报告称,相比在多个工具间来回切换,体验显著精简——不过定价细节仍然模糊。

### 3. 微软据报道将在自家产品中弃用 OpenAI 和 Anthropic 模型

一次戏剧性的转变:**微软正计划在其产品套件——包括 Excel、Outlook 和 Teams——中用自研 AI 模型替换 OpenAI 和 Anthropic 模型**。据 SiliconANGLE 率先报道、多家媒体确认,此举由成本考量驱动——微软寻求在大规模场景下降低对昂贵第三方 API 调用的依赖。

这一决定可能成为微软-OpenAI 关系的转折点——后者是 AI 时代最具标志性的合作。虽然微软可能继续提供第三方模型作为选项,但据报道,驱动 Office 365 全线 Copilot 的默认智能正在切换到内部研发的系统。

### 4. Meta 杀入 AI 编程市场

Meta 已正式进入 **AI 辅助编程市场**,推出一款旨在与 Anthropic 的 Claude Code 和 OpenAI 的 Codex 竞争的新工具。借助其 Llama 模型家族,Meta 的编程助手被定位为开放权重替代方案,企业可以自托管——直击那些限制了纯云端编程工具采用的隐私顾虑。

此举让本已拥挤的赛道更加白热化——GitHub Copilot、Cursor 和 Claude Code 一直在争夺开发者的心智。Meta 的开放路线可能吸引需要本地部署 AI 基础设施的受监管行业和政府机构。

### 5. Anthropic 和 OpenAI 面临来自中国的日益增长的威胁

新一波**廉价的中国 AI 模型**正以超出预期的速度缩小与西方领导者的性能差距。Bloomberg 和 Reuters 本周均报道,以 DeepSeek 为首的中国实验室模型如今在多个关键基准上已能与 Anthropic 和 OpenAI 的产品抗衡,而训练和运行成本只是零头。

这些进展给美国的 AI 芯片出口管制带来了战略拷问——出口管制本意是拖慢中国的进步。分析师认为,中国实验室展示的效率提升可能表明软件创新正在跑赢硬件限制,潜在地重塑全球 AI 版图。

### 6. DeepSeek 把廉价 AI 变成竞争武器

DeepSeek——这家今年早些时候以高性价比模型震撼业界的中国 AI 实验室——如今正**把低价变成战略优势**。通过以大幅低于 OpenAI 和 Anthropic 的价格提供 API 访问,DeepSeek 正吸引全球对价格敏感的开发者和初创公司。

据报道,该公司最新模型在多个推理基准上接近 GPT-5 级系统的水平,同时运行在较弱的硬件上。这一性价比正在迫使西方 AI 公司重新审视定价策略——此刻它们的盈利压力本已沉重。

### 7. OpenAI、Anthropic 和 Google 用 AI 积分资助初创公司

为了锁定下一代 AI 原生公司,**OpenAI、Anthropic 和 Google 正在向早期初创公司注入数百万美元的免费 API 积分**。这一战略既是获客,也是生态建设——目标是确保明天的爆款公司建立在各自的平台之上。

批评者担心,积分计划制造供应商锁定、扭曲市场,让初创公司日后难以更换供应商。据报道,监管者正在关注这一做法,尽管尚未有正式行动。就目前而言,"代币战争"只是 AI 主导权升级之战的又一条战线。
