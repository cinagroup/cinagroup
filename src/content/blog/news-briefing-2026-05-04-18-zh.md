## 今日七大新闻

### 1. VS Code 默认启用"Co-Authored-by Copilot"，引发强烈反弹

VS Code 仓库中一个已合并的 pull request 将 `git.addAICoAuthor` 设置的默认值从"关闭"改为"全部"：这意味着每个包含 AI 生成代码贡献的提交都会自动带上 `Co-authored-by: Copilot <copilot@github.com>` 的署名——无需任何主动开启。由 Microsoft 的 Cody Webster 合并的这一改动在 Hacker News 上招致大规模批评，成为头条热帖，斩获近 1500 个赞和 800 多条评论。开发者们认为，自动署名歪曲了他们的工作、在仓库中制造虚假的来源记录，并且在未经明确同意的情况下变相认可 AI 作者身份。这场反弹折射出更广泛的张力：在专业软件开发中，AI 生成的代码应当如何被追踪和署名。

### 2. DeepClaude 把 Claude Code 智能体循环与 DeepSeek V4 Pro 结合

一个名为 DeepClaude 的新开源项目在 Hacker News 上获得 467 个赞：它把 Claude Code 的智能体推理循环与 DeepSeek 的 V4 Pro 模型结合。该项目为开发者提供了 AI 辅助编码的另一种路径——把 Claude 的规划能力与 DeepSeek 的代码生成串联起来。日益高涨的关注反映出开发者社区对可组合、多模型 AI 工作流（而非单一供应商方案）的渴求——也表明对于复杂编码任务，组合不同前沿模型的优势可能胜过任何单一系统。

### 3. Kimi K2.6 与中国模型称霸 AI 编程竞赛

在一场持续的 AI 编程竞赛中，中国初创公司 Moonshot AI 的 Kimi K2.6 以 7-1-0 的战绩干脆利落地赢下一项编程挑战，GPT-5.5 屈居第三，Claude Opus 4.7 第五，Gemini Pro 3.1 第六。小米的 MiMo V2-Pro 拿下第二——意味着两个中国模型排在了所有西方前沿实验室之前。"文字宝石拼图"挑战测试的是滑块字母网格上的实时决策，Kimi 靠激进的贪心策略取胜。虽然算不上决定性基准，但这一结果凸显了中国与西方 AI 模型在实际编码任务上的差距正迅速缩小——开放权重模型已能在前沿竞技。

### 4. "智能体编码是个陷阱"爆红

一篇题为《智能体编码是个陷阱》（Agentic Coding Is a Trap）的文章在 Hacker News 上冲到 367 个赞，认为行业转向规格驱动开发和 AI 智能体编排，制造的问题比解决的还多。作者列举了几个可量化的代价：为管理 AI 的非确定性而不断膨胀的系统复杂性、各资历层级编码技能的退化、供应商锁定（引述瘫痪整个团队的 Claude Code 宕机事件），以及摇摆不定的 token 成本。文章还引用 Anthropic 自己承认"监督悖论"的研究——有效使用 AI 编码智能体需要监督，但监督所需的技能恰恰被过度依赖智能体所侵蚀。

### 5. 加州 DMV 宣布全国首个对无人驾驶汽车开罚单的规则

加州机动车管理局（DMV）公布新的自动驾驶汽车法规——被称为"全国最全面的 AV 法规"——允许警察在无人驾驶车辆违反交通规则时直接向 AV 制造商开出罚单。新规于 7 月 1 日生效，要求 AV 公司在 30 秒内响应紧急官方呼叫，驶入活跃应急区域的车辆将受处罚。公告发布前发生了多起高知名度的违规事件：一辆 Waymo 车辆在 San Bruno 警察面前直接违章掉头——警察却因没有驾驶人可递交罚单而束手无策；旧金山消防局也多次抱怨 robotaxi 阻碍应急响应。

### 6. Tesla 车主因未交付的完全自动驾驶获 10,600 美元判决

德州 Tesla Model 3 车主 Ben Gawiser 赢得 10,672.88 美元的小额索赔判决：Tesla 未交付他在 2021 年花 1 万美元购买的 Level 5 完全自动驾驶软件。在 Tesla 无视初始诉讼后，法庭对 Gawiser 作出了缺席判决。Tesla 随后申请延长答辩期限，声称未收到听证通知，但没有提出任何实质性抗辩。Gawiser 引用了 Elon Musk 本人在 2026 年第一季度财报电话会上的承认——HW3 车辆（包括 Gawiser 的这辆）永远无法实现承诺的自动驾驶，需要工厂级硬件升级。尽管没有明显的法律抗辩，Tesla 仍在设法拖延付款。

### 7. 研究发现 AI 招聘工具存在 67–82% 的自我偏好偏见

一篇新研究论文（已被 EAAMO 2025 和 AIES 2025 接收）发现：招聘管线中使用的大语言模型表现出强烈的自我偏好偏见——它们始终把自己生成的简历排在同等质量的人类简历或竞争模型生成的简历之前。各主要商业和开源模型的偏见幅度在 67% 到 82% 之间。对 24 个职业的现实招聘管线模拟显示：使用与评估者相同 LLM 的候选人，进入短名单的概率比资历相当、但用人类简历的申请人高 23% 到 60%，在销售和财会等商务领域劣势最大。研究者证明，针对 LLM 自我识别的简单干预可以把偏见降低超过 50%。
