# Flexina appearance port for CinaGroup

The site uses an original Astro implementation of the Flexina visual preset, connected to the existing CinaGroup content and EmDash runtime. This is a presentation change; it does not import a WordPress database or add WooCommerce, newsletter delivery, customer accounts, or demo business claims.

## Deliberate visual differences

The official CinaBrand and all business text replace the Flexina wordmark and dummy copy. Original photographs replace unlicensed demo media. The header has only the real social links and email, with no invented telephone, shopping cart, store or fake search. On small screens, numbered cards are horizontally scrollable with scroll snap, so all four remain readable without an unsolicited auto-advancing card carousel. Long localized titles may increase hero height to avoid clipping. Primary cyan buttons use dark text for readable contrast; content links use darker cyan in light mode. Dark mode is an additional supported adaptation. Demo newsletter, player, progress percentages and pricing toggles are omitted because the current business does not provide those functions or values.

## Initial homepage motion (2026-10-03)

Homepage motion enhances the existing composition without changing copy, layout or photographs. Each hero slide reveals its eyebrow, full heading, lead and action group in order, with 90 ms between groups and a 600 ms fade with a 14 px vertical offset. Selecting another slide replays those groups. Headings remain intact text nodes in all eight languages, so selecting, copying and reading them with assistive technology does not require reconstructed words. The existing 12-second rotation, previous/next controls, manual pause, mouse hover, keyboard focus and document-visibility pause rules remain in effect.

Quick links, the about composition, section headings, product cards, workflow items and CTA copy receive a subtle first-entry reveal through `flexina/HomeMotion.astro`. One IntersectionObserver unobserves each target after its first reveal. The 520 ms fade uses a 12 px vertical offset, with at most 210 ms of stagger; independent `translate` leaves the existing card hover transforms intact. No horizontal motion is added.

All content is visible in the server-rendered markup and has no motion-dependent hidden CSS. The initial Web Animations enhancement runs only when the browser supports the required APIs. With JavaScript unavailable or `prefers-reduced-motion: reduce`, content stays visible and the carousel can still be switched manually when JavaScript is available. In this initial implementation, enabling reduced motion immediately cancels active reveals and stops automatic rotation. Keyboard-focused reveal targets are not faded away. Astro navigation cancels animations, disconnects the observer and removes preference listeners before swapping pages; repeated page-load events do not create extra homepage observers. The next section specifies the subsequent visitor motion preference and site-wide extension; it is not an acceptance claim.

### Native Site Profile save and publish procedure

After the appearance schema extension has been applied to the intended environment, open native EmDash **Site profile → site** and select the locale being edited. Use the fields labelled **Design —** and **Motion —** to configure the presets in the table above. These settings are shared across locales; continue editing translated titles, descriptions and other business copy in their own locale.

1. Enter colors as complete `#RRGGBB` values. Clearing either color field is supported: after publication, Primary resets to #03c2f6 and Secondary to the #42d7ff gradient companion. Arbitrary CSS, short hex values and URLs are rejected.
2. To reset numeric settings, enter **1000** for reveal duration in milliseconds, **12** for hero interval in seconds, and **10** for wave duration in seconds. Do not clear these number inputs: the native form converts an empty number to 0, which the bounds reject. Existing untouched nullable fields retain the reviewed defaults.
3. Save the changes as a draft. The public site continues using the previous published settings. Use native **Publish** when the appearance is ready for public pages, then reload representative pages and language variants.
4. Native publication propagates shared appearance settings to the published entries in English, Chinese, Japanese, Korean, Russian, Spanish, Portuguese and French. It does not publish another locale's pending text edits. An independent draft keeps its explicitly changed appearance values and localized copy; unchanged shared fields receive the newly published values. Review that draft before subsequently publishing it.

Administrator **Motion — Animation style: off** always takes precedence over footer visitor On. Otherwise visitor Off stops animation, Auto follows the system preference, and an explicit visitor On can enable animation despite system Reduce. Component switches remain effective: On does not enable a disabled footer wave or disabled hero autoplay. A wave also pauses when it is offscreen or the document is hidden.
